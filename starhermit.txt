# The Starhermit account that owns this game (the submitter's user id).

# The authoritative match simulation. The platform runs this script server-side
# in its Jint sandbox, ticking it at the script-declared rate (game.tickRateHz
# = 30) — see spec.md section 12. The runtime loads the same file for offline
# practice, prediction and the menu's backdrop. Realtime Rooms
# (/api/v1/realtime, /ws/v1/realtime) are used for lobby/roster only.
server=server.js

# Default keyboard controls (spec.md section 6). The runtime binds the actions
# from these lines; players rebind keys and pads in its Options menu (the game's
# CONTROLS screen opens it). Tank-style steering: up/down run forward/back,
# left/right rotate the player. The shoot key is contextual: a quick tap passes,
# holding charges a shot.
# Format: control.<action>=<KeyboardEvent.code>[+<code>...] | <label>
control.up=KeyW+ArrowUp | Run forward
control.down=KeyS+ArrowDown | Backpedal
control.left=KeyA+ArrowLeft | Turn left
control.right=KeyD+ArrowRight | Turn right
control.shoot=Space+KeyJ | Shoot (hold) / tap to pass
control.pass=KeyL | Pass
control.tackle=KeyK | Slide tackle / pressure
# The library cover art.
cover=cover.jpg

# The game (spec.md section 16): the StarHermit runtime runs this repository as
# a script game — `starhermit <this directory>`. The platform ignores engine.*
# keys; the runtime reads them with name=, server= and the control.* lines.
# engine.api is the host-API major version, engine.entry the TypeScript entry
# module; the capabilities are the platform (rooms, sockets, leaderboards,
# replays, chat), voice, clipboard (invite links) and storage (the game's
# settings: language, mute, voice). engine.gamepad.* give the actions their
# default pad controls; players rebind keys and pads in the runtime's Options.
engine.api=1
engine.entry=engine/src/main.ts
engine.version=1.22.0
engine.capabilities=platform,voice,clipboard,storage
engine.gamepad.up=LeftStickUp+DpadUp
engine.gamepad.down=LeftStickDown+DpadDown
engine.gamepad.left=LeftStickLeft+DpadLeft
engine.gamepad.right=LeftStickRight+DpadRight
engine.gamepad.shoot=West+RightTrigger
engine.gamepad.pass=South
engine.gamepad.tackle=East
